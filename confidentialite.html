JARVIS

Règles de confidentialité · Privacy policy — mise à jour le 1er novembre 2026

Jarvis est une application personnelle, utilisée par son seul auteur. Elle n’a ni serveur, ni base de données, ni compte utilisateur : elle fonctionne dans le navigateur de l’appareil de son auteur. Un seul traitement planifié s’exécute en dehors de l’appareil : un résumé du courrier, lancé par GitHub Actions dans le dépôt privé de l’auteur (voir plus bas).

Données traitées

  • Notes : lues et écrites dans un dépôt GitHub privé appartenant à l’utilisateur.
  • Google Agenda : les rendez-vous sont lus, créés ou supprimés directement auprès de Google, à la demande de l’utilisateur, uniquement pour être affichés et gérés dans Jarvis. Les autorisations demandées sont la liste des agendas (lecture) et les événements (lecture et écriture).
  • Gmail : la boîte dédiée à Jarvis (jarvis.executive.ia@gmail.com) est lue pour afficher les messages et en faire un résumé, les messages peuvent être envoyés ou mis à la corbeille (jamais supprimés définitivement), uniquement à la demande de l’utilisateur ou par le résumé planifié qu’il a activé. Les autorisations demandées sont gmail.modify (lecture, classement, corbeille) et gmail.send (envoi).
  • Assistant IA : quand l’utilisateur le sollicite, sa demande, les notes ou les messages nécessaires sont envoyés au fournisseur de modèle qu’il a choisi avec sa propre clé.

Stockage et partage

Les jetons d’accès et clés sont conservés dans le stockage du navigateur de l’appareil et dans le dépôt GitHub privé de l’utilisateur (pour les partager entre ses appareils et pour le résumé planifié du courrier, qui s’exécute avec GitHub Actions dans ce même dépôt). Ils ne sont envoyés qu’au service concerné. Aucune donnée n’est vendue, partagée avec des tiers, utilisée à des fins publicitaires ou pour entraîner des modèles d’IA, et aucun humain ne lit les données Google de l’utilisateur, hormis lui-même. L’utilisation des données reçues des API Google respecte la Google API Services User Data Policy, y compris ses exigences d’usage limité (Limited Use).

Révocation

L’accès à Google peut être retiré à tout moment depuis Jarvis (Réglages → Google Agenda ou Courrier → Déconnecter) ou depuis myaccount.google.com/permissions.

English summary

Jarvis is a personal, single-user web app with no backend of its own. Google Calendar and Gmail data (the user’s own dedicated mailbox) are accessed directly from the browser, and by one scheduled GitHub Actions job in the user’s private repository, only to display, summarise and manage the user’s own events and messages. The data is never shared, sold, read by humans other than the user, or used for advertising or AI training. Tokens are stored on the user’s device and in the user’s private repository. Access can be revoked at any time.
